## 1.2.0 · Recovered BM shows · 29 October 2026

Wave, Orbit spine circle, Spinner, Ambient points, Stars, Rotating image, Rings,
and Bloom join Vibe shift, giving the rotation 17 looks. The reviewed ports keep
their source colors and intentional motion, fixed spatial color texture, and
smooth light mixing over the spandex. OSC-position lights, video mapping, and
MIDI input remain excluded. See [the source notes](recovered-shows.md).

## Initial public source · 28 October 2026

Released 28 October 2026 at [SonicSphere/TinySphere](https://github.com/SonicSphere/TinySphere) with the live simulator on [GitHub Pages](https://sonicsphere.github.io/TinySphere/). The complete source, contribution guides, bundled assets, and six selected screenshots are public. The original project code and materials use the [MIT license](../LICENSE); separately credited third-party material retains its own rights and notices.

This release includes the latest approved main behavior through Site version 53: continued center zoom to a 330° diagonal stereographic lens, exact-pole stability, 80/10/10 dice visibility, two camera controls with the approved View reset pose, and desktop S screenshots without a menu or readouts. `main` automatically deploys only after its build, tests, and distribution checks pass.

## Contributor source

- Organize the browser source by light shows, themes, engine, audio, camera, environment, controls, settings, and assets.
- Extract all nine existing shows without changing their sampled artwork output.
- Add a small, validated registry for shows and four named visual-theme presets.
- Add `listThemes()` and `applyTheme()` to the existing browser API.
- Add working examples, content scaffolding, a local contributor studio, portable build/test commands, and a GitHub Actions workflow.
- Add a plain Markdown README, contributor guides, architecture/API documentation, and the six app screenshots selected by Jeremy. Original selected files and provenance are included; earlier authoring presets are retained separately. The separate HTML introduction is retired.
- Keep generated builds, historical experiments, local QA receipts, hosting identity/configuration, and machine-specific files out of the source package.

## Preserved behavior

The selected arrival state, 212 fixtures, accepted Aggressive geometry, matte white spandex wraps, modeled LED mapping, photo-guided v2 floor, full interior camera, smooth dolly leveling, music path, permanent controls, creator credits, and half-second appearance wipe remain.

New shows join the existing Vibe shift registry. Named theme presets are available through the local studio and API; the production control layout is unchanged. The captured artwork reference test covers all nine built-in shows across 216 time/palette/audio cases.
